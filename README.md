# Eye 2048

눈동자의 시선 방향(상·하·좌·우)으로 조작하는 2048 게임입니다.
브라우저의 웹캠과 [MediaPipe Face Mesh](https://github.com/google/mediapipe)를 사용해
홍채(iris)의 위치를 추적하고, 보정된 중앙으로부터의 편차로 이동 방향을 결정합니다.

## 실행 방법

ES 모듈을 사용하므로 정적 파일 서버가 필요합니다 (`file://`로는 동작하지 않음).

```bash
# 디렉터리에서 임의의 정적 서버 실행
python3 -m http.server 8000
# 또는
npx serve .
```

브라우저에서 `http://localhost:8000` 접속.

## 사용 방법

1. **카메라 시작** 버튼을 눌러 웹캠을 켭니다 (브라우저 권한 허용).
2. 정면을 응시한 상태에서 **중앙 보정** 버튼을 누릅니다.
3. 시선을 위/아래/왼쪽/오른쪽으로 옮기면 해당 방향으로 타일이 이동합니다.
4. 키보드(방향키 또는 WASD)로도 조작할 수 있습니다.

**민감도**와 **쿨다운**을 조정해 본인의 시선 변화 폭에 맞출 수 있습니다.
민감도가 너무 높으면(값이 큼) 잘 안 움직이고, 너무 낮으면 의도치 않게 자주 움직입니다.

## 파일 구조

- `index.html` — UI 레이아웃
- `style.css` — 스타일
- `game.js` — 2048 게임 로직 (`Game2048` 클래스)
- `eyeTracker.js` — 시선 추적 (`EyeTracker` 클래스)
- `main.js` — 두 모듈을 연결하고 DOM 이벤트를 바인딩
